# Dabara playground

A browser version of Dabara — nothing to install. It runs the same language in WebAssembly.

**Status: not published yet.** The playground is built and deployed by the project's own pipeline; its
address will be added here and on the [main page](../README.md) when it goes live.

Differences from the `dabara` program: modules (`shigo`/`fitar`) and file functions
(`karanta_fayil`, `rubuta_fayil`, `akwai_fayil`) are not available in the browser — they give the errors
`DBR-027` / `DBR-028`. Everything else is the same.
